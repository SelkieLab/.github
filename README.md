# .github

SelkieLab 的组织级仓库，放两类东西：

| 路径 | 作用 |
|---|---|
| `profile/README.md` | 组织主页内容，显示在 https://github.com/SelkieLab |
| `profile/assets/` | 组织主页用的图片（banner 等） |
| `CONTRIBUTING.md` | 所有仓库共用的贡献指南 |
| `SECURITY.md` | 漏洞报告方式与本组织的安全底线 |
| `CODE_OF_CONDUCT.md` | 行为准则 |

组织级默认文件靠这个仓库生效：GitHub 会在每个没有自己同名文件的仓库里
自动展示这里的版本。

## 改组织主页

改 `profile/README.md`，推到 `main` 即可，几秒后 https://github.com/SelkieLab 就更新。
